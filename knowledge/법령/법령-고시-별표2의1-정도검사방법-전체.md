> 환경측정기기의 형식승인·정도검사 등에 관한 고시 별표2의1 (2026-01-01 시행)
> 수질(용존산소·화학적산소요구량·생물화학적산소요구량·총질소·총인·총유기탄소·수소이온농도·부유물질) 연속자동측정기 정도검사 방법

---

## 1. 반복성 시험

### 시험 방법
1. 제로용액으로 **3회 이상** 반복 측정 → 제로 표준편차(SD_Z) 계산
2. 스팬용액으로 **3회 이상** 반복 측정 → 스팬 표준편차(SD_S) 계산
3. 판정: **SD_Z와 SD_S 중 큰 값(SDi의 최대값)**을 측정범위로 나눠 합격 여부 결정

### 계산식
```
반복성(%) = SDi의 최대값 / 측정범위 × 100   (%-항목: COD·TN·TP·TOC·SS·BOD)
  · SDi의 최대값 = 제로측정값 표준편차와 스팬측정값 표준편차 중 큰 값 (식 QM0302.1-1)
  · 분모는 평균이 아니라 측정범위임에 주의
※ DO·pH는 표준편차 절대값 자체로 판정(mg/L·pH, 나눗셈 없음, 식 QM0301.1-1)
```

### 합격 기준
- TOC·TN·TP·SS·COD·BOD: 측정범위의 **3.0% 이하**
- DO: **0.30 mg/L 이하** (절대값, % 아님)
- pH: **pH 0.10 이하** (절대값)
- TU·CL (먹는물): **2.0% 이하**

---

## 2. 드리프트 시험 (Drift)

### 시험 방법
1. 시험 시작 시 제로용액 측정 2회(Z1, Z2), 스팬용액 측정 2회(S1, S2)
2. **4시간 대기** (COD·TOC·TN·TP·SS·BOD, 30분 이상 간격 2회 이상 측정 / 식 QM0302.1)
   - **DO 예외**: 시험 시작 후 **2시간 경과**, **5분 이상 간격 3회 이상** 측정(식 QM0301.1-3)
   - 먹는물 TU·CL: 2시간
3. 시험 종료 시 제로용액 측정 2회(Z3, Z4), 스팬용액 측정 2회(S3, S4)

### 계산식
```
제로드리프트(%) = |평균(Z3,Z4) - 평균(Z1,Z2)| / 측정범위 × 100
스팬드리프트(%) = |평균(S3,S4) - 평균(S1,S2)| / 측정범위 × 100
```

### 합격 기준
- TOC·TN·TP·SS·COD·BOD: 제로·스팬 각각 **5.0% 이하**
- DO: 제로드리프트 **0.20 mg/L 이하** / 스팬드리프트 **0.30 mg/L 이하**
- pH: 제로·스팬 각각 **pH 0.10 이하**
- TU·CL (먹는물): 제로·스팬 각각 **3.0% 이하**

---

## 3. 직선성 시험 (Linearity)

### 시험 방법
1. 교정 실시 후 **측정범위의 (45±5)% 부근 단일 농도**를 주입
2. 해당 농도를 **3회 이상 측정 후 평균값** 산출 (식 QM0302.1-4)
3. 평균값과 주입농도값의 오차율 계산으로 합격 여부 결정
4. TU·CL: M 1점만 측정
   > ※ 3농도점(25/45/65%) 방식은 형식승인 성능시험법이며 정도검사법이 아님

### 계산식
```
직선성 오차(%) = (측정값 - 기준값) / 기준값 × 100
```

### 합격 기준
- TOC·TN·TP·SS·COD·BOD·TU·CL: 주입농도값의 **±5.0% 이내**
- DO: **직선성 시험 없음** (QM0301.1 정도검사 항목: 반복성·제로/스팬드리프트·응답시간·온도보상)
- pH: **pH ±0.10 이내**

---

## 4. 현장적용계수 시험

### 시험 방법
1. 현장 배출수 채취 → 수분석(주시험법)으로 분석 농도(Ai) 2회 측정
2. 동시에 TMS 자동측정값(Ci) 2회 기록
3. 위 과정 2회 반복 (총 2세트)

### 계산식
```
현장적용계수(%) = |수분석 평균(Ai) - TMS 평균(Ci)| / 수분석 평균(Ai) × 100
```

### 합격 기준
| 항목 | % 기준 | 절대값 기준 | 비고 |
|------|--------|-----------|------|
| TOC | 15.0% | 0.45 mg/L | 둘 중 하나 만족 |
| TN | 15.0% | 1.50 mg/L | 둘 중 하나 만족 |
| TP | 15.0% | 0.060 mg/L | 둘 중 하나 만족 |
| SS | 20.0% | 1.0 mg/L | 둘 중 하나 만족 |
| COD | 15.0% | 3.0 mg/L | 둘 중 하나 만족 |
| BOD | 20.0% | 1.0 mg/L | 둘 중 하나 만족 |
| pH | — | **±0.20** (절대값) | pH 단위 |
| DO | 해당 없음 | — | DO는 현장적용계수 없음 |
| TU·CL | 해당 없음 | — | 먹는물은 현장적용계수 없음 |

### 배출기준 식 재계산 조건 (TOC 한정, 식 QM0306.1-8)
**TOC에 한함.** 주시험법 측정값 평균이 **배출기준(배출허용기준·방류수수질기준·하천·호소 수질오염사고 경보기준)의 50% 미만**일 경우, 분모를 수분석 평균(Ai) 대신 **배출기준**으로 바꾼 식으로 재계산하여 그 값이 **15.0% 이하**여야 합격이다. (자동 적합 처리가 아니라 배출기준 식으로 재계산해 15.0% 이하 판정임)
> ※ 이 50% 규칙은 TOC 세부기준(QS0306.1)·계산식(QM0306.1-8)에만 존재하며, COD·TN·TP·SS·BOD에는 없음.

### 생략 조건 (물환경보전법 시행령)
수질TMS 관제센터가 정도검사일 기준 **3개월 이내** 상대정확도시험을 실시한 경우 현장적용계수 시험 생략 가능

## 5. 응답시간 시험 (T90)

### 시험 방법
1. 안정화 상태에서 시험 시작
2. 스텝 변화 주입 (저농도→고농도 또는 반대)
3. 측정값이 변화량의 90%에 도달하는 시간(T90) 측정

### 합격 기준
| 항목 | T90 기준 |
|------|---------|
| TOC·TN·TP·SS·COD·BOD | **15분 이하** |
| DO | **2분 이하** |
| pH | **30초 이하** |
| TU (먹는물) | **10분(90%) 이하** |
| CL (먹는물) | **2분(90%) 이하** |

---

## 6. pH 온도보상 시험 (pH 전용)

### 시험 방법
온도 변화 시 온도보상 기능의 정확도 확인.

### 합격 기준
**pH ±0.20 이내**

---

## 검사 순서 및 판정 원칙

```
반복성 → 드리프트 → 직선성 → 현장적용계수 → 응답시간
(pH: 온도보상 추가)

판정: 모든 항목 합격 → 적합
      1개 항목이라도 초과 → 부적합
```
