## 성능시험 항목 및 기준

TU는 **먹는물 분야** — 수질TMS보다 엄격한 기준 적용.

| 항목 | 기준 | 비고 |
|------|------|------|
| 측정범위 | **10 NTU 이하** 설정 가능 | 원수용 측정기기는 예외 |
| 최소검출한계 | **0.1 NTU 이하** | 별표2: 3 × SDi |
| 반복성 | 측정범위의 **2.0% 이하** | (SDi)최대값/측정범위×100 (수질TMS 3.0%보다 엄격) |
| 제로드리프트 (24h) | 측정범위의 **3.0% 이하** | (수질TMS 5.0%보다 엄격) |
| 스팬드리프트 (24h) | 측정범위의 **3.0% 이하** | |
| 직선성 | 주입농도값의 **±5.0% 이하** | **3점 측정** (최대눈금값 30/50/80%) |
| 응답시간 (T90) | **10분(90%) 이하** | |
| 전압변동 안정성 | 측정범위의 **3.0% 이하** | 정격전압 ±10% |
| 절연저항 | **5 MΩ 이상** | 500V 절연저항계 (성능시험 전용) |
| 내전압 | **AC 1,000V·100mA 1분** 이상 없음 | 성능시험 전용 |
| 종합성능시험 | 168시간(7일) 연속가동, 7일 제로·스팬드리프트 각 **5.0% 이하** | 성능시험 전용 |

> TU는 현장적용계수 시험 없음 (먹는물 분야)
> 직선성 측정점: **3점** (최대눈금값의 30%, 50%, 80%) — 수질TMS와 동일

## 표준용액

| 용액 | 내용 |
|------|------|
| 제로용액 | 0.2 μm 막여과 정제수 (0.02 NTU) |
| 스팬용액 | 탁도표준용액 (측정범위 최대값 85% 이상) |
| 직선성용액 | 최대눈금값의 **30%, 50%, 80% (3점)** |

→ 상세 제조: [[표준용액-TU-포르마진]]

---

## 직선성 기준값
```
직선성(%) = Ms / 주입농도값 × 100
Ms = |시험용액 농도값 - 측정값| 의 최대값
주입점: 최대눈금값의 30%, 50%, 80% (3점)
예: 측정범위 0~10 NTU → 3, 5, 8 NTU
```
