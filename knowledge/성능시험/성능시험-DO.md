# DO (용존산소) 성능시험

links: [[성능시험-개요]], [[표준용액-DO]], [[정도검사-항목별기준]], [[법령-환경측정기기고시]]

## 근거
고시 별표1(형식승인 성능기준) TS 0301.1 + 별표2 성능시험방법 TM0301.1 — 용존산소 연속자동측정기와 그 부속기기 (측정방법: 격막형 폴라로그래프식/격막형 갈바니 전지식/광학식, 측정범위 0~20 mg/L)

---

## 성능시험 항목 및 기준

DO 성능기준은 대부분 농도(mg/L) 절대값 기준이며, 현장적용시험만 비율(%) 기준(5.0 %)이다.

| 항목 | 기준 | 비고 |
|------|------|------|
| 최소검출한계 | **≤ 0.10 mg/L** | 절대값 |
| 반복성 | **≤ 0.30 mg/L** | 절대값 (SDi 최대값) |
| 제로드리프트 (24h) | **≤ 0.20 mg/L** | 절대값 |
| 스팬드리프트 (24h) | **≤ 0.30 mg/L** | 절대값 |
| 응답시간 | **2분 이하** | 제로용액에서 1.0 mg/L 이하 지시까지의 시간 |
| 간섭시험 | **± 0.30 mg/L 이내** | 염소가 10·20 g/L |
| 온도보상시험 | **± 0.30 mg/L 이내** | 10·20·30 ℃ |
| 전압변동률 | **≤ 0.20 mg/L** | 정격전압 ±10 % |
| 절연저항 | **≥ 2.0 MΩ** | 500 V 절연저항계 |
| 내전압 | AC 1,000 V·100 ㎃ 1분 이상無 | 별표2 §10 시험방법 |
| 현장적용시험 | **≤ 5.0 %** | ★형식승인엔 있음(비율 기준), 정도검사엔 없음 |
| 종합성능시험 | 168시간(7일) 가동 이상無 / 7일 제로드리프트 ≤0.30·스팬드리프트 ≤0.50 mg/L | 별표1 6항 |

> ★ DO는 형식승인 별표1에 **현장적용시험(≤ 5.0 %)이 존재**한다 — 정도검사(별표1의1)엔 없으므로 혼동 주의.

- 수온·기압 변화 시 포화 DO값 재보정 필수
