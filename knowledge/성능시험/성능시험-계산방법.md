# 성능시험 계산방법 (형식승인용)

tags: [성능시험, 계산방법, 반복성, 드리프트, 직선성, 절연저항, 내전압, 종합성능]
links: [[성능시험-개요]], [[정도검사-계산방법]], [[법령-환경측정기기고시]]

## 개요
성능시험 계산 항목은 정도검사와 공통 항목 + 성능시험 전용 항목으로 구성.
→ 공통 항목(반복성·드리프트·직선성·응답시간·현장적용시험)은 계산식 구조가 [[정도검사-계산방법]]과 유사하나, 형식승인 성능시험은 측정 조건이 다르다(반복 6회·드리프트 24시간·직선성 3점 농도). 값 출처는 형식승인 별표1(성능기준)·별표2(성능시험방법)이다.

---

## 공통 항목 (정도검사와 동일)

### 반복성 (Repeatability)
```
반복성(%) = (SDᵢ)의 최대값 / 측정범위 × 100
```
- (SDᵢ)의 최대값 = 제로 측정값 표준편차와 스팬 측정값 표준편차 중 큰 값
- 제로·스팬용액 각 6회(정도검사는 3회) 이상 측정 → 큰 값으로 판정
- DO·pH: 측정범위로 나누지 않고 절대 표준편차(SD) 적용 — DO는 mg/L, pH는 pH 단위

### 제로·스팬 드리프트 (Zero/Span Drift)
```
드리프트(%) = |24시간 후 측정값 - 초기 측정값| / 측정범위 × 100
```
- 24시간 연속 운전 후 측정
- DO·pH: 측정범위 대신 절대값(mg/L, pH) 기준

### 직선성 (Linearity)
```
직선성 오차(%) = (측정값 - 주입농도값) / 주입농도값 × 100
```
- 수질TMS: 측정범위의 (25±5)%·(45±5)%·(65±5)% 3점 주입 → 농도별 오차 중 절대값 최대로 판정
- 먹는물(TU·CL): 최대눈금값의 30%·50%·80% 3점 주입 → |농도값−측정값| 최대/주입농도값
- 판정: 주입농도값의 ±5.0 % 이내 (pH만 pH ±0.10 이내)

### 응답시간 T90
```
T90 = 측정값이 스팬 변화의 90%에 도달하는 시간 (단위: 분 또는 초)
```
- 응답시간 성능기준이 있는 항목: DO 2분·pH 30초·TOC 15분·TU 10분(90%)·CL 2분(90%)
- COD·BOD·TN·TP·SS: 형식승인 별표1에 응답시간 성능기준 없음

### 현장적용시험 (현장적용계수)
```
현장적용시험(%) = |Ci − Ai| / Ai × 100
```
- Ci = 연속자동측정기 측정값, Ai = 주시험방법 측정 평균값 (현장 2곳 이상, 시료별 5개 이상)
- 대상: DO·COD·BOD·TN·TP·TOC·pH·SS (먹는물 TU·CL은 현장적용시험 없음)
- 판정 = **OR 기준**(주시험법 기준농도의 X % 또는 Y mg/L 이하 중 하나만 만족하면 적합):

| 항목 | 현장적용시험 기준 |
|------|------------------|
| COD | 15 % 또는 3.0 mg/L |
| BOD | 20 % 또는 1.0 mg/L |
| TN | 15 % 또는 1.50 mg/L |
| TP | 15 % 또는 0.060 mg/L |
| TOC | 15 % 또는 0.45 mg/L (측정값 3.0 mg/L 이하 적용) |
| SS | 20 % 또는 1.0 mg/L |
| DO | 5.0 % |
| pH | pH 0.20 |

- 파생모델: 현장적용시험 제외

## 성능시험 전용 항목

### 절연저항 (Insulation Resistance)
```
절연저항(MΩ) = 인가전압(V) / 측정전류(A)
```

**시험 방법:**
1. 500 V 절연저항계(KS C 1301/1302)로 측정
2. 전원단자 ↔ 외부단자 간 측정
3. 측정기 동작정지 상태에서 실시

**합격 기준:** 수질(DO·COD·BOD·TN·TP·TOC·pH·SS) **2.0 MΩ 이상** / 먹는물(TU·CL) **5 MΩ 이상**

### 내전압 (Dielectric Withstand Voltage)
**시험 방법:**
1. 정격주파수 교류전압 **AC 1,000 V, 100 mA** 인가 (전원단자 ↔ 외부단자 사이)
2. **1분간** 유지
3. 이상 유무 확인 (단, 전지내장형은 적용하지 않음)

**합격 기준:** 이상 없음

### 종합성능시험 (7일 연속)
**시험 방법:**
1. 시험실 조건에서 **168시간(7일) 연속 가동**
2. 가동 초기와 종료 시 각각 제로용액·스팬용액을 3회 이상 측정하여 평균을 구함
3. 초기 평균과 7일 후 평균(C₇)의 차로 **7일 제로드리프트·스팬드리프트**를 산출

**판정 (7일 드리프트 기준):**
- 수질(측정범위 %항목): 7일 제로/스팬 드리프트 각 측정범위의 **7.0 %** 이하
- DO: 7일 제로드리프트 **0.30 mg/L**, 스팬드리프트 **0.50 mg/L** 이하
- pH: 7일 제로/스팬 드리프트 각 **pH 0.20** 이하
- 먹는물(TU·CL): 7일 제로/스팬 드리프트 각 측정범위의 **5.0 %** 이하

**목적:** 장기 안정성(드리프트 누적) 검증

## 성능시험 vs 정도검사 계산 차이 요약

| 항목 | 정도검사 | 성능시험 |
|------|---------|---------|
| 반복성 | 동일 | 동일 |
| 드리프트 | 유사 (24h) | 유사 (24h·7일) |
| 응답시간 | 동일 | 동일 (COD·BOD·TN·TP·SS는 기준 없음) |
| 직선성 | 유사 (기준값 방식) | 주입농도값 기준·3점(수질 25/45/65%, 먹는물 30/50/80%) |
| 현장적용시험 | 있음 | 있음 (DO·pH 포함, TU·CL 제외, 파생모델 제외) |
| 절연저항 | **없음** | **있음** (수질 2.0 MΩ·먹는물 5 MΩ 이상) |
| 내전압 | **없음** | **있음** (AC 1,000 V·1분) |
| 종합성능시험 | **없음** | **있음** (7일 연속·제로/스팬 드리프트) |
