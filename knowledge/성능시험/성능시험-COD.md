# COD (화학적산소요구량) 성능시험

tags: [성능시험, COD, 화학적산소요구량, 형식승인, 수질TMS]
links: [[성능시험-개요]], [[표준용액-COD]], [[정도검사-항목별기준]], [[법령-환경측정기기고시]]

## 근거
고시 별표1(형식승인 구조·성능) + 별표2(성능시험방법) — 수질 분야 자동측정기
- 측정방법: **100 ℃ 과망간산칼륨법**(산성 또는 알칼리성) 또는 동등 이상
- 측정범위: **0 ～ 250 mg/L** 범위 이내 설정 가능

---

## 성능시험 항목 및 기준

| 항목 | 기준 | 비고 |
|------|------|------|
| 최소검출한계 | **1.0 mg/L 이하** | 측정범위 5% 용액 6회 이상 |
| 반복성 | 측정범위의 **3.0% 이하** | SDᵢ(제로·스팬 표준편차) 최대값 ÷ 측정범위 ×100 (RSD 아님) |
| 제로드리프트 (24h) | 측정범위의 **5.0% 이하** | 제로용액(5%이하), (C_z24−C_z0)/측정범위 |
| 스팬드리프트 (24h) | 측정범위의 **5.0% 이하** | 스팬용액(90%이상), (C_s24−C_s0)/측정범위 |
| 직선성 | 주입농도값의 **±5.0% 이내** | (25±5)·(45±5)·(65±5)% 3점 |
| 포도당변동성시험 | 주입농도값의 **±5.0% 이내** | (30±5)·(50±5)·(80±5)% 3점 (COD 전용) |
| 전압변동률 | 측정범위의 **3.0% 이하** | 정격전압 ±10% |
| 현장적용시험 | 주시험법 기준농도의 **15.0% 또는 3.0 mg/L 이하** | **OR** (둘 중 하나 만족) |
| 절연저항 | **2.0 MΩ 이상** | 500V 절연저항계, 동작정지 상태 |
| 내전압 | 교류 **1,000V·100㎃·1분간** 이상 없음 | 전지내장형 제외 |
| 종합성능시험 | 168시간(7일) 제로·스팬드리프트 각 **7.0% 이하** | 7일 연속가동 |

> ⚠️ COD엔 **응답시간(T90) 조항 없음** — 원문 별표1·별표2 성능항목에 부재. (응답시간 조항은 DO 2분·TOC 15분·pH 30초·TU 10분·CL 2분에만 존재)

## 표준용액

| 용액 | 내용 |
|------|------|
| 제로용액 | 화학적산소요구량 표준액 조제방법(수질오염공정시험기준) 기준 제로용액 (드리프트 시 5%이하) |
| 스팬용액 | 측정범위 **90% 이상** (스팬드리프트·종합성능시험 기준) |
| 직선성용액 | 측정범위 **(25±5)%, (45±5)%, (65±5)%** 3점 |
| 포도당시험액 | 측정범위 (30±5)%, (50±5)%, (80±5)% 3점 |

## KHP와 TOC 동시 사용

KHP(프탈산수소칼륨)는 TOC 표준물질:
- KHP 1000 mg/L → TOC 470.6 mg/L
- COD 1175.2 mg/L 값은 **다이크로뮴산칼륨법(ThOD)** 기준 이론값

> ⚠️ 본 COD 자동측정기 형식승인 측정방법은 **100 ℃ 과망간산칼륨법**이므로 KHP의 ThOD(1175.2 mg/L) 값이 그대로 적용되지 않는다. COD 표준용액은 **수질오염공정시험기준의 화학적산소요구량 표준액 조제방법**에 따른다(별표1 일반사항 8호).
