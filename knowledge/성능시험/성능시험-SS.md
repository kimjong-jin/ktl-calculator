## 근거
고시 별표1 (형식승인) — 수질 분야 부유물질 연속자동측정기 (TS 0308.1)
측정방법: 중량검출법 또는 광산란법 / 측정범위: 0 ~ 2,000 mg/L
성능시험방법 별표2: TM 0308.1

---

## 성능시험 항목 및 기준 (형식승인 별표1 TS 0308.1)

| 항목 | 기준 | 비고 |
|------|------|------|
| 최소검출한계 | **1.0 mg/L 이하** | 3 × SDi |
| 반복성 | 측정범위의 **3.0% 이하** | (SDi)최대값 / 측정범위 × 100 |
| 제로드리프트 (24h) | 측정범위의 **5.0% 이하** | |
| 스팬드리프트 (24h) | 측정범위의 **5.0% 이하** | |
| 직선성 | 주입농도값의 **±5.0% 이내** | 25·45·65% 3점 |
| 전압변동률 | 측정범위의 **3.0% 이하** | 정격 ±10% 전압 |
| 절연저항 | **2.0 MΩ 이상** | 500V 절연저항계 |
| 내전압 | **AC 1,000V · 100mA 1분** 이상 없음 | |
| 현장적용시험 | **20.0% 또는 1.0 mg/L 이하** | OR (둘 중 하나 만족) |
| 종합성능시험 | 168h(7일) 연속 가동, 7일 제로·스팬드리프트 **각 7.0% 이하** | |

> ⚠️ SS에는 **응답시간(T90) 조항이 없음** (별표1 TS 0308.1 성능 4항에 미수록). 응답시간 조항이 있는 항목은 DO·TOC·pH·TU·CL 뿐.

## 주의사항
- SS 표준용액은 **침강** 발생 — 주입 직전 충분히 교반
- 현장적용시험은 비율 기준(20.0%) **또는** 절대값 기준(1.0 mg/L) 중 **하나만 만족(OR)**하면 적합 (별표1 원문 "20.0 % 또는 1.0 mg/L 이하"). ※ "모두 만족(AND)"은 정도검사 별표1의1의 "변동성이 큰 시료" 예외 조항에만 해당 — 형식승인 성능시험에는 해당 없음
- 반복성 = (SDi)최대값 / 측정범위 × 100 (제로·스팬 표준편차 중 최대값), RSD(σ/평균) 아님
