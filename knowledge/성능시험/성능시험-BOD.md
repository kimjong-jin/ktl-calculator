## 근거
형식승인 별표1(성능기준)·별표2(성능시험방법) — 생물화학적산소요구량 연속자동측정기 (산소전극/산소센서 방식, 측정범위 0～200 mg/L)

---

## 성능시험 항목 및 기준 (형식승인 별표1 4. 성능)

| 항목 | 기준 | 비고 |
|------|------|------|
| 측정범위 | **0 ～ 200 mg/L** 범위 내 설정 가능 | 별표1 2.(2) |
| 최소검출한계 | **1.0 mg/L 이하** | 3 × SDi |
| 반복성 | 측정범위의 **3.0% 이하** | SDi최대값/측정범위×100 |
| 제로드리프트 (24h) | 측정범위의 **5.0% 이하** | |
| 스팬드리프트 (24h) | 측정범위의 **5.0% 이하** | |
| 전압변동률 | 측정범위의 **3.0% 이하** | 정격전압 ±10% |
| 현장적용시험 | 주시험법 기준농도의 **20.0% 또는 1.0 mg/L 이하** | **둘 중 하나(OR) 만족** |
| 절연저항 | **2.0 MΩ 이상** | 500V 절연저항계 |
| 내전압 | **AC 1,000V·100mA 1분** 가하여 이상 없음 | 전지내장형 제외 |
| 종합성능시험 | **168시간(7일)** 연속가동, 7일 제로·스팬드리프트 각 **7.0% 이하** | 별표1 6 |

> ⚠️ 형식승인 별표1 BOD 성능 조항엔 **직선성·응답시간(T90) 항목이 없음** (다른 항목과 혼동 금지).

## 표준용액

| 용액 | 내용 |
|------|------|
| 표준 확인액 | GGA (포도당 150 mg/L + 글루타민산 150 mg/L) |
| 기대값 | BOD₅ ≈ 198 ± 30 mg/L |
| 제로용액 | DO ≥ 9 mg/L 포화 희석수 (BOD ≈ 0) |

→ 상세 제조: [[표준용액-BOD]]

## BOD 자동측정기 특수성

BOD TMS는 5일 배양 대신 **단시간 호흡률 측정** 또는 **상관식** 사용:
- UV 흡광도 또는 호흡률로 BOD 추정
- GGA 표준액으로 응답 직선성 검증
- DO 전극 성능이 측정 정확도에 직접 영향 → [[표준용액-DO]] 관리 중요
