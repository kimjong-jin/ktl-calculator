## 성능시험 항목 및 기준

CL은 **먹는물 분야** — 수질TMS보다 엄격한 기준 적용.

| 항목 | 기준 | 비고 |
|------|------|------|
| 반복성 | 측정범위의 **2.0% 이하** | (SDi)최대값/측정범위×100, 제로·스팬 중 큰 값 |
| 제로드리프트 (24h) | 측정범위의 **3.0% 이하** | |
| 스팬드리프트 (24h) | 측정범위의 **3.0% 이하** | |
| 직선성 | 주입농도값의 **±5.0% 이하** | **3점 측정** (최대눈금값 30·50·80%) |
| 응답시간 (T90) | **2분(90%) 이하** | 시약식은 미측정 |
| 절연저항 | **5 MΩ 이상** (500V 절연저항계) | 성능시험 전용 |
| 내전압 | 교류 **1,000V·100mA 1분** 이상 없음 | 성능시험 전용 |
| 종합성능시험 | 168시간(7일) 연속, 7일 제로·스팬드리프트 **5.0% 이하** | 성능시험 전용 |

> 그 외 별표1 성능: 측정범위 10 mg/L 이하 설정 / 최소검출한계 0.1 mg/L 이하 / 전압변동 안정성 측정범위의 3.0% 이하
> CL은 현장적용계수 시험 없음 (먹는물 분야)
> 직선성 측정점: **30·50·80% 3점** (별표2 성능시험방법)

| 직선성용액 | 최대눈금값의 30·50·80% 3점 |

→ 상세 제조: [[표준용액-CL]]

## 직선성 측정점 (별표2 성능시험방법)
```
제로·스팬 교정 후 최대눈금값의 30%, 50%, 80% 용액 3점 주입
직선성(%) = |시험용액 농도값 − 측정값|의 최대값 / 주입농도값 × 100 ≤ ±5.0%
예: 측정범위 0~2 mg/L → 0.6 / 1.0 / 1.6 mg/L 주입
```
