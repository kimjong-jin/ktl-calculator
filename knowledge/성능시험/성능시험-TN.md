# TN (총질소) 성능시험

tags: [성능시험, TN, 총질소, 형식승인, 수질TMS]
links: [[성능시험-개요]], [[표준용액-TN]], [[정도검사-항목별기준]], [[법령-환경측정기기고시]]

## 근거
고시 별표1 — 수질 분야 자동측정기 (측정방법: 자외선 흡수법, 카드뮴 환원법 또는 동등 이상). 측정범위 0～600 mg/L

---

## 성능시험 항목 및 기준

| 항목 | 기준 | 비고 |
|------|------|------|
| 최소검출한계 | **1.0 mg/L 이하** | 별표1 성능 (1) |
| 반복성 | 측정범위의 **3.0% 이하** | SDi최대값/측정범위 (RSD 아님) |
| 제로드리프트 (24h) | 측정범위의 **5.0% 이하** | |
| 스팬드리프트 (24h) | 측정범위의 **5.0% 이하** | |
| 직선성 | 주입농도값의 **±5.0% 이내** | M1·M2·M3 3점 |
| 전압변동률 | 측정범위의 **3.0% 이하** | 정격전압 ±10% |
| 현장적용시험 | **15% 이하** 또는 **1.50 mg/L 이하** | **OR (둘 중 하나 만족)** |
| 절연저항 | **2.0 MΩ 이상** (500V 절연저항계) | 성능시험 전용 |
| 내전압 | AC **1,000V**·100㎃ 1분 이상 없음 | 성능시험 전용 |
| 종합성능시험 | 168시간(7일) 연속 운전 전 항목 기준 만족 | 성능시험 전용 |

> ⚠️ TN에는 **응답시간 조항이 없다** (형식승인 별표1·성능시험방법 별표2 모두 없음). 응답시간은 DO·TOC·pH·TU·CL 항목에만 존재.

## 표준용액

| 용액 | 내용 |
|------|------|
| 제로용액 | TN ≤ 0.1 mg/L 초순수 |
| 스팬용액 | KNO₃ 용액 (측정범위 85% 이상) |
| 직선성용액 | M1(15%), M2(45%), M3(90%) 농도 |

→ 상세 제조: [[표준용액-TN]]

## 현장적용시험 기준
- **15% 이하 OR 1.50 mg/L 이하** (둘 중 하나만 만족하면 적합) — 형식승인 별표1 원문: "현장적용시험은 15.0 % 또는 1.50 mg/L 이하이어야 한다"
- ⚠️ AND(둘 다 만족)는 **정도검사 별표1의1**의 "변동성 큰 시료" 예외 조항일 뿐, 형식승인 성능기준엔 없음
- ⚠️ 50% 자동 적합 규칙 없음 — 배출기준 50% 미만 시 배출기준 식 재계산은 TOC(QS0306.1) 한정. TN에는 미적용
