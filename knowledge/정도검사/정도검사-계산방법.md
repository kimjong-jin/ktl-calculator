## 반복성 (Repeatability)

### 계산식
```
반복성(%) = (SDi)의 최대값 / 측정범위 × 100   (식 QM0302.1-1)
```
- (SDi)의 최대값 = 제로측정값 표준편차와 스팬측정값 표준편차 중 최대값
- ⚠️ 분모는 **측정범위** (평균 아님)
- DO·pH는 나누지 않고 **표준편차(SD) 절대값** 그대로 판정 (식 QM0301.1-1 / QM0307.1-1)

### 방법
1. 제로용액(Z) 3회 이상 측정 → 표준편차 SD_Z 계산
2. 스팬용액(S) 3회 이상 측정 → 표준편차 SD_S 계산
3. 둘 중 **큰 SD**를 측정범위로 나누어 판정 (제로·스팬 드리프트 데이터 활용 가능)

### 합격 기준
- 수질TMS: RSD ≤ 3.0%
- 먹는물(TU·CL): RSD ≤ 2.0%
- DO: ≤ 0.30 mg/L (절대값)
- pH: ≤ pH 0.10 (절대값)

## 드리프트 (Drift)

### 제로드리프트 계산식
```
제로드리프트(%) = |평균(Z3,Z4) - 평균(Z1,Z2)| / 측정범위 × 100
```

### 스팬드리프트 계산식
```
스팬드리프트(%) = |평균(S3,S4) - 평균(S1,S2)| / 측정범위 × 100
```

### 측정 순서
- 초기 측정 → **대기 후** 최종 측정 (제로·스팬 각각)
- 대기 시간: **DO·pH는 2시간**, COD 등 수질TMS 항목은 **4시간** (시험 시작 후 경과)

### 합격 기준
- 수질TMS: ≤ 5.0% (제로·스팬 각각)
- 먹는물(TU·CL): ≤ 3.0%
- DO: 제로 ≤ 0.20 mg/L, 스팬 ≤ 0.30 mg/L
- pH: ≤ pH 0.10

---

## 직선성 (Linearity)

### 계산식
```
직선성 오차(%) = (측정값 - 기준값) / 기준값 × 100
```

### 기준값
```
기준값 = 측정범위 × 0.9 / 2 = 측정범위의 45%
```

### 방법
- 정도검사: 측정범위의 **(45±5)% 부근 단일 농도를 3회 이상 측정**한 평균값으로 판정 (식 QM0302.1-4)
- (형식승인 TM0302.1-5는 25/45/65% 3점 측정 — 정도검사와 구분)
- 먹는물(TU·CL)은 M 1점만 측정 후 판정

### 합격 기준
- 전 항목 공통: ±5.0% 이내
- pH: ±0.10 이내
- ※ DO는 직선성 시험 없음 (반복성·드리프트·응답시간·온도보상시험만)

## 현장적용계수 (Field Application Factor)

### 계산식
```
현장적용계수(%) = |수분석 평균(Ai) - 현장측정 평균(Ci)| / 수분석 평균(Ai) × 100
```

### 측정 방법
1. 현장에서 배출수 채취하여 수분석(주시험법)으로 측정 → Ai (2회 평균)
2. 동시에 TMS 현장측정값 → Ci (2회 평균)
3. 2회차 반복 실시

### 합격 기준 (항목별 허용오차)
| 항목 | 기준 | 절대값 기준 |
|------|------|-----------|
| TOC | 15.0% | 0.45 mg/L |
| TN | 15.0% | 1.50 mg/L |
| TP | 15.0% | 0.060 mg/L |
| SS | 20.0% | 1.0 mg/L |
| COD | 15.0% | **3.0 mg/L** |
| BOD | 20.0% | 1.0 mg/L |
| pH | — | **±0.20** (절대값) |

### 배출기준 재계산 규칙 (TOC 한정)
측정값이 **배출기준(배출허용기준·방류수수질기준·하천/호소 수질오염사고 경보기준)의 50% 미만**일 경우, 자동 적합이 아니라 **배출기준에 의한 식으로 재계산**한 값이 **15.0% 이하**여야 함 (식 QS0306.1).
- ⚠️ 이 50% 규칙은 **TOC(QS0306.1)에만** 존재 — COD·TN·TP·SS에는 없음.

### 변동성 큰 시료 처리
비율 기준과 절대값 기준 **모두** 만족해야 함
(예: SS는 20% 이하 AND 1.0 mg/L 이하 동시 만족)

---

## 응답시간 (T90)

### 정의
측정값이 스텝 변화의 90%에 도달하는 시간

### 합격 기준
| 항목 | 기준 |
|------|------|
| TOC | 15분 이하 |
| DO | 2분 이하 |
| pH | 30초 이하 |
| TU (먹는물) | 10분(90%) 이하 |
| CL (먹는물) | 2분(90%) 이하 |

---

## 최종 판정 원칙
- 모든 검사 항목이 합격 기준 이내 → **적합**
- 1개 항목이라도 기준 초과 → **부적합**
- 현장적용계수 미실시 시 해당 항목 제외하고 판정
